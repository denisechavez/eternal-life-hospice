Pre-publish SEO checks are advisory: report problems with each page URL and a
plain-language fix, never block a publish or silently rewrite site content.
Keep reports private, outside visitor-accessible website directories.

**Why:** The owner explicitly requested automated checks before every publish,
with reporting rather than automatic SEO changes.

**How to apply:** Separate the read-only audit from fixes. Missing blog, resource
and city breadcrumbs were explicitly authorized as shared presentation changes;
do not rewrite approved Journal copy or publication dates to add them. Keep the
existing service-hero design without a new top breadcrumb bar. Report remaining
wording mismatches rather than renaming H1s or menu labels without review.
