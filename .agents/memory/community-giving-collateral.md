# Community-giving collateral

First deliverable: `exports/diagrams/full-circle-of-care.png` — "full circle" graphic
(end-of-life care giving back to beginning of life) supporting the Children's Workshop
for the Arts Endowment at VCCF (501(c)(3), Tax I.D. 77-0165029), which funds children's
arts programs of the Oxnard Performing Arts Center. Audience: heads of county foundations.

**Rule — standard disclosure block (architect-approved; reuse verbatim on all giving collateral):**
"Eternal Life Hospice is an independent supporter. [Org] names appear for donation
direction only and do not imply endorsement or affiliation. Charitable giving is
separate from, and never connected to, any care or referral decision."

**Why:** first draft failed review — "Trusted partnership" wording implied formal
affiliation/endorsement by VCCF; philanthropy copy must never read as AKS/Stark
inducement or claimed partnership.

**How to apply:** keep giving copy neutral and verifiable (describe the endowment
mechanics, not a 'partnership'); include the disclosure footnote; donation path =
VCCF donation page, Fund Name "The Children's Workshop".
