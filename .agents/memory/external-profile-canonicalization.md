All social profiles use `https://eternallifehospice.com` as their website destination. Provider-facing links may use `https://eternallifehospice.com/refer`.

**Why:** The organization is establishing the Replit-hosted canonical site as the independent public destination while the older Netlify copy remains only as a frozen fallback.

**How to apply:** Keep social bios, link-in-bio pages, pinned posts, channel links, QR-linked profile destinations, and future external-profile updates on the canonical domain. Never replace it with the Replit subdomain, Netlify, or either legacy domain.
