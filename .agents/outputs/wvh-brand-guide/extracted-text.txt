02 FOUNDATION
Westlake-specific brand architecture
LOCAL
CLARITY
Westlake Village Hospice leads with its local 
name, a direct response and a clear 
explanation of what happens next.
Four-pillar framework
Do not use Clinical Confidence, Guided Presence, Whole-Person 
Comfort or Compliance-Led Care.
Agency distinction
The four pillars belong exclusively to Eternal Life Hospice and must 
not appear in Westlake materials.
Westlake message
Use the approved Westlake message hierarchy, voice and local 
positioning in this guide.
Shared relationship
The sister-agency relationship may be stated when useful without 
importing Eternal Life Hospice's pillar system.

19 WEB PRODUCTION
Readability floors
Whitespace must come from layout and copy editing rather than smaller text.
15 px
Absolute floor
Eyebrows and short metadata only. Never use for paragraphs, navigation or 
buttons.
17 px
Mobile body
Default minimum for supporting copy, cards, forms and instructional text.
18 px
Desktop body
Default for paragraphs and service explanations.
4.5:1
Text contrast
Required for normal text. Test text against its actual rendered background.
44 px
Preferred target
Buttons and primary controls should provide at least a 44 × 44 px active area.
No decorative label may become unreadable to preserve a composition.

21  WEB PRODUCTION
Responsive type tokens
Production CSS
:root {
  --font-display: "Canela", Georgia, serif;
  --font-sans: "Avenir Next", Avenir, sans-serif;
  --text-eyebrow: clamp(0.9375rem, 0.25vw + 0.88rem, 1rem);
  --text-body: clamp(1.0625rem, 0.25vw + 1rem, 1.125rem);
  --text-lead: clamp(1.125rem, 0.55vw + 1rem, 1.375rem);
  --text-h1: clamp(2.5rem, 4.2vw, 4.5rem);
}
.eyebrow { line-height: 1.4; letter-spacing: 0.1em; }
p { line-height: 1.6; max-width: 68ch; }
NON-NEGOTIABLE
Use rem or clamp() for scalable text.
Allow browser zoom to 200%.
Never disable text resizing.
Do not place essential copy inside images.
Load font-display: swap and test fallbacks.
The approved wordmark remains an image asset 
with meaningful alternative text. All other copy 
remains live HTML text.
