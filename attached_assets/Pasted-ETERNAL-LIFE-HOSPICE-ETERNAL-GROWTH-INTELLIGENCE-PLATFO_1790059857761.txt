ETERNAL LIFE HOSPICE
ETERNAL GROWTH INTELLIGENCE — PLATFORM REORGANIZATION

We are reorganizing the current Marketing & Census workspace into a cleaner executive business-intelligence system.

NEW PLATFORM NAME:

ETERNAL GROWTH INTELLIGENCE

Subtitle:

Performance · Marketing · Census · Expansion

The guiding principle is:

WHAT GETS MEASURED GETS MANAGED.

The primary navigation should focus on measurable outcomes, performance, trends, acquisition, census and market expansion.

Content production should no longer occupy the main performance navigation.

==================================================
CORE OPERATING MODEL
==================================================

Eternal Growth Intelligence should answer:

1. What is happening?
2. What is driving it?
3. Where is growth occurring?
4. Where is performance weakening?
5. What requires attention?
6. What sources are producing calls, referrals, admissions and eventually census?

The system should distinguish clearly between:

MEASURE / ANALYZE / MANAGE

and

CREATE / REVIEW / PUBLISH

The second function will live in a separate workspace called:

ETERNAL STUDIO

IMPLEMENTATION SEQUENCE
==================================================

Before making broad structural changes:

1. Inventory the existing navigation.
2. Inventory existing working dashboard components.
3. Map each existing component into the new architecture.
4. Identify duplicate or obsolete sections.
5. Confirm currently connected data sources.
6. Identify metrics that can populate immediately.
7. Identify metrics awaiting sources.
8. Preserve all working integrations.
9. Create a migration map.

Then implement the new navigation and page organization.

Do not modify the public Eternal Life Hospice website.

This task applies only to the Eternal Growth Intelligence application.
