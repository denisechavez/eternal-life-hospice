`cred-achc.png`

- exact file path
- current file size

- intrinsic dimensions
- every HTML file that references it

- Preserve transparency if the original uses transparency.

- Report the final WebP file size and percentage reduction.

## Task 4 — Correct the coverage statement

Search the deployed site for all occurrences of:

- `No Deductibles`
- `No Copays`
- `No Deductibles · No Copays`
- any equivalent absolute claim stating that hospice care always has no patient cost

Report every file and location where the statement appears.

Replace the absolute claim with this approved wording:

`Medicare hospice care is generally covered with little or no out-of-pocket cost for eligible patients.`

Where a shorter badge or label is required, use:

`Medicare Hospice Benefit`

Do not make claims that:

- all services are free
- every patient has no deductible
- every patient has no copay
- every insurance plan provides identical coverage

Preserve the existing design and spacing as closely as possible.
