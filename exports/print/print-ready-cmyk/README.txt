ETERNAL LIFE HOSPICE — PRINT-READY CMYK FILES (send THESE to the press)
======================================================================
Every file in this folder is already converted to CMYK and locked to the brand
color builds. SEND THESE FILES AS-IS. Tell the printer: "Files are CMYK — print
as supplied, do NOT re-convert from RGB." Re-converting is what makes plum go
muddy/blue and gold go flat.

The editable RGB design masters stay one level up in exports/print/ (and
exports/print/press-kit/). Keep those for future edits; never send them to print.

WHAT TO SEND
- Referral rack cards (5):           print-ready-cmyk/eternal-life-referral-card-1…5-*-CMYK.pdf
- Older single rack card:            print-ready-cmyk/eternal-life-rack-card-CMYK.pdf
- Press kit — presentation folder:   print-ready-cmyk/press-kit/eternal-life-presentation-folder-CMYK.pdf
- Press kit — 4 pillar rack cards:   print-ready-cmyk/press-kit/eternal-life-rackcard-1…4-*-CMYK.pdf

LOCKED BRAND BUILDS (all collateral matches these)
- Deep Plum  C69 M90 Y45 K53   (~PANTONE 5185 C / 519 C)
- Plum       C65 M90 Y37 K28   (~PANTONE 518 C)
- Gold       C22 M28 Y57 K0    (~PANTONE 4525 C; metallic alt 871 C)
- Cream      C2  M4  Y6  K0    (~paper white / PANTONE 9043 C)
Full table, press fixes, and trim/bleed specs: ../referral-rack-cards-PRINT-SPECS.txt

NOTES
- Page sizes and page counts are unchanged from the RGB masters (verified).
- Conversion is a faithful CMYK build (ghostscript), so what you see in these
  files is exactly the documented brand build. Gradients/tints in some cards
  read as variants of the four core colors — that is expected and on-brand.
- Pantone values are closest visual references — confirm on a Color Bridge book
  or a physical proof before the full run.
