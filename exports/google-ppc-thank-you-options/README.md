open it in a browser to review desktop and mobile layouts. Fonts, logos and the
care photograph are embedded; no React installation or external asset host is
required. The HTML files contain no JavaScript, tracking or submission handling.

the original 1080 × 1350 photograph, not a screenshot. For a sharper, full-width
Retina version, please supply the same licensed photograph at 2560 pixels wide
or larger. Upscaling alone will not restore detail. Logos have ample resolution
at the sizes used.
