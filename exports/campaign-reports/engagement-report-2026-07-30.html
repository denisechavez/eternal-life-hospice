How to Run the Suppression Review (at Send #6)

After send #6 lands (est. week of August 28 – September 7, 2026), run:

# Analysis only (safe to run any time — no changes made)
BREVO_API=<key> node exports/campaign-reports/engagement-review.js --dry-run

# Suppress: blacklist never-engaged contacts in Brevo
BREVO_API=<key> node exports/campaign-reports/engagement-review.js --suppress

# Alternative: move to re-engagement list instead of hard blacklist
BREVO_API=<key> node exports/campaign-reports/engagement-review.js --move-to-list

Note on Brevo IP whitelisting: The Brevo account restricts API calls to authorized IPs. The script must be run from a machine whose IP is in Brevo's authorized list (Settings → Security → Authorized IPs), or the IP restriction must be temporarily removed. The Replit environment IP is not currently authorized.

The script outputs an HTML report to exports/campaign-reports/engagement-report-YYYY-MM-DD.html and prints a tier summary to stdout. Run with --min-sends 6 (default) to ensure suppression is blocked until at least 6 campaigns have been sent.

💡 Ask the agent at send #6:
"Run the engagement review and suppress unresponsive contacts from our email list."
The agent will run the script against the Brevo API, generate an updated version of this report with real tier data, and apply suppression after confirming the contact count with you.
