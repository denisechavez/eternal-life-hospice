- **Offer/Update post:** Use one of the weekly posts above

## Quick Posting Rules
1. **Same headline + body across all platforms** — only format/length changes
2. **Never claim medical efficacy** for integrative therapies (sound bath, aromatherapy = "comfort and wellbeing, not a cure")
3. **Never name competitors** or make comparative superiority claims
4. **Always include phone + website** on every post
5. **Hashtags:** 3-5 on Instagram, 5-8 on LinkedIn/Facebook, 0-2 on GBP
6. **Images:** Use the asset library — each post gets its own image, never reuse the same image back-to-back
